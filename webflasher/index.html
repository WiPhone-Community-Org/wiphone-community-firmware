If the phone doesn't show up

  1. Use Chrome or Edge on a computer — other browsers cannot flash.
  2. Use a USB cable that carries data — many charging cables don't.
  3. Close anything else using the serial port (serial monitors, IDEs). An error like Failed to execute 'open' on 'SerialPort' means another program is holding the port right now.
  4. On Windows, install the CP210x or CH340 driver, then replug.
  5. Keep the phone powered on while flashing, and keep this page open until it says it finished.

What this does

Your browser talks to the phone over USB (Web Serial) and writes the firmware directly — nothing to install, no Python, no command line. The phone reboots itself when it finishes.
